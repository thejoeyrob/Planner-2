FKBC Coach Console — quick guide

1. BuildAdd work, break or interval sections. All main fields edit directly on the planner.
2. CoachesTap the coach thumbnail in a section. Overall coach updates new work sections.
3. RoundsOpen Rounds on a section to set work rounds, rest/changeover and final-rest behaviour.
4. GradingToggle Grading on only the section you need, then pick a belt and syllabus technique.
5. Quick TypeFocus any technique/detail box. The chip tray tracks the visible viewport so it remains above the iPad keyboard.
6. TimerTap the main timer stage to hide/show chrome. Full-body coach art slides in without covering the core timer text.
7. Live editingChoose Edit during the lesson, change the planner, then Resume. The remaining time is retained.
